# OFELIYA

Рогалик-выживание в стиле Vampire Survivors — мини-приложение для мессенджера **MAX**.
Персонаж стреляет автоматически, игрок управляет только движением, собирает опыт, выбирает
улучшения и пытается продержаться 5 минут до босса.

## Стек

- **Phaser 3 + TypeScript + Vite** — сама игра (весь арт генерируется кодом, ассетов нет).
- **MAX Bridge** (`window.WebApp`, подключается CDN-скриптом в `index.html`) — авторизация,
  хаптика, шаринг результата. В обычном браузере безопасно деградирует в no-op
  (см. `src/systems/MaxBridge.ts`).
- **`@maxhub/max-bot-api`** — для серверной части бота (не нужен для клиентской сборки).

## Запуск

```bash
npm install
npm run dev      # дев-сервер http://localhost:5173
npm run build    # прод-сборка в dist/ (tsc + vite)
npm run preview  # локальный просмотр прод-сборки
```

Управление: тап/драг по экрану — виртуальный джойстик (появляется под пальцем),
на десктопе — WASD/стрелки.

## Публикация в MAX

1. `npm run build` → в `dist/` лежит статика с относительными путями (`base: './'`).
2. Разместить `dist/` на любом HTTPS-хостинге — VK Cloud, Yandex Cloud, GitHub Pages
   (требование MAX: только `https://`).
3. В [business.max.ru/self](https://business.max.ru/self): ваш бот → «Расширенные настройки» →
   «Настроить» → вставить URL приложения, выбрать кнопку «Играть».
4. Диплинк запуска: `https://max.ru/<бот>?startapp=<payload>`.

Публикация открыта для юрлиц, ИП и самозанятых РФ (верификация в кабинете MAX).

## Структура

```
src/
  main.ts               — запуск Phaser (+ window.__game в dev для автотестов)
  scenes/               — Boot (генерация текстур), Menu, Game, UI (HUD/модалки)
  game/                 — Player, Enemy, Bullet, Gem, WaveDirector, UpgradeSystem,
                          RunState (статы забега), Joystick, config (весь баланс)
  systems/              — MaxBridge (обёртка window.WebApp), SaveSystem (localStorage), Sfx (WebAudio-синтез)
```

Вся интеграция с MAX изолирована за интерфейсом `MaxBridge` — игра работает в любом браузере,
мост подменяется заглушкой. Баланс (урон, волны, кривая опыта, босс) — в `src/game/config.ts`.

## Цикл забега

0:00–5:00 — волны (роевики → бегуны → громилы), элиты каждые 2 минуты, на 5:00 спавнится босс.
Убить босса — победа; смерть — проигрыш. Рекорды (время/убийства/уровень) хранятся в localStorage.
10 улучшений: урон, скорострельность, мультивыстрел, пробивание, скорость, прочность, магнит,
орбитальный клинок, нова, регенерация.
