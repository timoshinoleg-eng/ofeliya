## Completion rule

Code existence plus green local tests is a candidate, not completed whole-master-task acceptance. Production-build comparison is actual UI evidence; synthetic cadence is not real device FPS. Main merge needs separate owner permission. Authorized deployment still requires validation, backup, exact pushed SHA and live verification. Later visual/social/animation/HiDPI phases remain individually scoped and measured.
