# P0 FIRST MINUTE COPY — QA отчёт (2026-11-21)

Задача: GitHub issue #320 (P0-2). Сделать первые 60 секунд и весь экранный
русский текст понятными холодному Telegram-пользователю на 320×568, без
изменений игрового контракта. Ветка `p0/kimi-first-minute-copy-20261121`.

Правила, которым подчинялись все правки: канон терминов —
`docs/GAME_LANGUAGE_BIBLE.md` («прочность», не HP; «РНК»; «лизис»
допустим, если объяснён действием); точные числа и семантика эффектов
сохранены 1:1; никаких новых модальных окон; шрифты не уменьшались,
геометрия и тап-зоны не менялись.

## 1. Аудит: что вызывало непонимание

| Где | Было | Проблема для холодного игрока |
|---|---|---|
| `UIScene.ts` ONBOARDING_COPY, шаг 1 | «Веди джойстик, чтобы двигаться.» | Джойстика на экране нет — он появляется только под пальцем (floating joystick). Игрок ждёт видимого джойстика. |
| Шаг 2 | «Автоогонь» / «Оружие стреляет само.» | «Автоогонь» — внутренний термин; у вируса «оружие» — метафора без подсказки, что делать. |
| Шаг 3 | «…это опыт для мутаций.» | «Опыт» — утечка концепции XP; канон — РНК запускает мутацию. |
| Шаг 5 | «Крупную клетку-хозяина не стреляй… до цитолиза.» | Калька «клетка-хозяина» (канон: клетка организма); «цитолиз» не расшифрован при первом употреблении; «не стреляй» с ошибкой управления. |
| `UpgradeSystem.ts` `hp.desc` | «Увеличивает запас здоровья…» | Смешение терминов: карта говорит «прочность», описание — «здоровье». |
| `UpgradeSystem.ts` `infect.desc` | «Стой рядом с клеткой…» | Не сказано, какая клетка заражается (иммунные клетки не заражаются). |
| `UpgradeSystem.ts` `nova.desc` | «Круговая волна сама срабатывает…» | Тавтология: не сказано, когда и по чему она бьёт. |
| `UpgradeSystem.ts` `factory.desc` | «Лизис клетки даёт…» | «Лизис» без объяснения на карте, которая может выпасть раньше карты ЦИТОЛИЗ. |
| Босс ИММУННЫЙ ПРАЙМ | Нет ни одной подсказки о контрплее | Игрок не знает: уклоняться из красного круга, бить после атаки (фаза восстановления, +25% урона; разрыв мембраны лизисом — +65%). |

Что НЕ стали менять (проверено, канонично и понятно): хинты хост-клеток
(`КЛЕТКА ОРГАНИЗМА · ЗАРАЗИ РЯДОМ` / `ЗАРАЖЕНИЕ НАЧАЛОСЬ · ОСТАВАЙСЯ
РЯДОМ` / `ВНЕ ЗОНЫ · ЗАРАЖЕНИЕ ОСЛАБЕВАЕТ`) — короткие, действие ясно;
HUD `РНК N/M → МУТАЦИЯ`; стартовый интро-текст; карточки с пинами
тестов (lysis name/desc, nova shortName — `test:mutation-copy`);
каталог `UiCopy.ts` (пинится `test:ui-copy`).

Контрплей Прайма в хинте соответствует механике (`Enemy.updateBossPressureAttack`,
`BossVulnerability`): телеграф → круговая волна → фаза восстановления
(+25% входящего урона). Хинт идёт через существующий канал
`showContextHint`, который босс-ривил сам приостанавливает и проигрывает
после — новых окон и пересечений с HUD нет.

Все проценты/числа карточек (±25%, 15%, +22%/+8%, +30%/+8%, +1 РНК/+10%,
0,6/с, 40) не тронуты; менялся только текст описаний. RNG, урон, HP,
длительность стадии, механики босса, спавны, прогрессия, RunState/версии,
Score/Duel/Daily/Stars, стор, фичефлаги геймплея — не затрагивались.
