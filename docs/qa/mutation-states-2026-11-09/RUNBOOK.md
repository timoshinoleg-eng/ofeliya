# QA: фиксированные состояния экрана мутаций (A/B/C + B-mid) + трофей первого босса

База сверки данных: `main 2bd6320b1d7f8e1076e7dd70dfafb46800efd86a`. Ветка
`qa/mutation-screen-b-c-trophy` (наследует `qa/mutation-screen-states` = main +
экран A). Браузерная проверка (Chromium, ноутбук) — пройдена; физическая
приёмка на Samsung S20+ — **NOT_RUN, за владельцем**.

## Что добавлено в этой ветке

Продолжение «Био-мембраны» по пакету Muse (тексты спец-карт — единый
источник `LEGENDARIES` / `EVOLUTIONS`):

- **Экран B — блок рецепта на карточке.** Строка «Синергия →» заменена блоком
  рецепта (`src/game/recipeProgress.ts`): заголовок «Рецепт «СИНГУЛЯРНОСТЬ»»
  (с отметкой «— последнее условие», если карта закрывает рецепт), строки
  шагов с фактическими стеками («МЕМБРАННЫЙ ИМПУЛЬС — 3/3 ✓»,
  «РНК-АФФИНИТЕТ — 1/2 → 2/2») и пояснение внутри блока. Прогресс считается
  из живого состояния; «закроет ли выбор рецепт» проверяется настоящим
  apply()+bump() против клона состояния.
- **Экран C — карта эволюции** с новым эффектом «Круговая волна: новый облик.
  Открывает «Цепь лизиса»»; числа волны по-прежнему даёт «Мембранный импульс».
- **Трофей первого босса (ИММУННЫЙ ПРАЙМ).** Трофейный экран: заголовок
  «ЛЕГЕНДАРНЫЙ ТРОФЕЙ», подзаголовок со сбросом в «Сердце» (уровень 1,
  прочность 100, мутации заново) и сохранением трофея на забег; правило
  «Выбери одну из двух — вторая исчезнет.» (число — из фактического
  предложения); условная сноска про лимит легендарных: до босса не брали —
  «второй можно найти дальше», брали — «последняя легендарная этого забега»
  (`TROPHY_COPY` / `trophySlotNote` в `src/game/UiCopy.ts`). На картах
  легендарных с `heartHint` — строка «В Сердце: …».
- **Гарантия посадки.** Если стек со сноской всё равно не влезает, контент
  модалки ужимается равномерно (`fitScale`, предел 0.75 — синтетический случай
  трёх легендарных карт на 320×520; штатный трофей ужимается до ~0.94).
  Факты раскладки публикуются в данных модалки: `squash`, `fitScale`.
- **QA-фикстуры трофея** (`src/game/qaTrophyStates.ts`): `?qaTrophy=fresh|one|
  used|rhythm` через тот же QA-гейт, что и `?qaMutation`.

## Как открыть каждое состояние

QA-гейт: dev-сервер (`npm run dev`) или сборка с `VITE_QA_TOOLS=1`. Без гейта
параметр игнорируется. Открыть игру и сразу стартовать забег — модалка
появится сама через обычный путь, выбор — обычным тапом.

| Состояние | URL | Что внутри |
|---|---|---|
| A | `?qaMutation=A` | «ПОСЛЕДНИЙ НОСИТЕЛЬ» (легендарная) + «РЕЦЕПТОРНЫЙ ЗАХВАТ» + «ЦИТОЛИЗ», свежее состояние |
| B | `?qaMutation=B` | «РНК-АФФИНИТЕТ» (последнее условие рецепта) + «РЕЦЕПТОРНЫЙ ЗАХВАТ» + «ЦИТОЛИЗ», стеки nova 3/3 + magnet 1/2 |
| B-mid | (проба) | nova 2/3, magnet 0/2: блок рецепта называет оставшееся условие, без отметки «последнее условие» |
| C | `?qaMutation=C` | «СИНГУЛЯРНОСТЬ» (критическая) + «РЕЦЕПТОРНЫЙ ЗАХВАТ» + «ЦИТОЛИЗ», стеки nova 3/3 + magnet 2/2 |
| Трофей fresh | `?qaTrophy=fresh` | 0 легендарных до босса; «ХИЩНИК ЯДРА» + «НУЛЕВАЯ ТОЧКА»; сноска «второй можно найти дальше» |
| Трофей one | `?qaTrophy=one` | 1 легендарная до босса («ПОСЛЕДНИЙ НОСИТЕЛЬ», не тронут); та же пара; сноска «последняя легендарная этого забега» |
| Трофей used | `?qaTrophy=used` | Как one, но спасение носителя уже потрачено в «Кровотоке» |
| Трофей rhythm | `?qaTrophy=rhythm` | Длинное условие: «РИТМ МИОКАРДА» + «ХИЩНИК ЯДРА», стадия — Сердце |

### На телефоне (Samsung S20+)

1. Сборка с QA-флагом: `VITE_QA_TOOLS=1 npm run build` → отдать `dist/` с
   любого статического хоста в локальной сети (или открыть dev-сервер
   ноутбука по LAN-адресу: `npm run dev -- --host`, телефон в той же сети).
2. Открыть `http://<host>/?qaMutation=A` (затем B, C, затем
   `?qaTrophy=fresh|one|used|rhythm`).
3. Проверить по чек-листу ниже. Скриншоты — системным жестом; запись экрана —
   штатной функцией Samsung.

## Чек-лист приёмки

- Ровно три карточки (два у трофея); порядок как в таблице выше.
- Пары «было → стало» с названием характеристики и единицей:
  A — время заражения **1250 → 1025 мс**, радиус заражения **58 → 62,6 ед.**;
  урон взрыва **26 → 33,8** (без единицы), радиус взрыва **150 → 162 ед.**.
  B — радиус подбора РНК **121,5 → 164 ед.**; выбор «РНК-аффинитета» лишь
  выполняет условия рецепта (СИНГУЛЯРНОСТЬ появится следующим предложением),
  эволюция сама не применяется.
- **Блок рецепта (экран B):** заголовок «Рецепт «СИНГУЛЯРНОСТЬ» — последнее
  условие», строки «МЕМБРАННЫЙ ИМПУЛЬС — 3/3 ✓» и «РНК-АФФИНИТЕТ — 1/2 →
  2/2», пояснение «После выбора рецепт будет готов.». В середине пути
  (B-mid) — заголовок без отметки, пояснение «Останется: мембранный импульс
  2/3.».
- «ПОСЛЕДНИЙ НОСИТЕЛЬ»: Условие, Эффект, цена и строка про облик читаются до
  тапа. Выбор резервирует страховку; срабатывание — только от смертельного
  урона: остаётся 1 прочности, теряется 25 % прогресса уровня, обычные враги
  исчезают, форма мутации 8 секунд.
- «СИНГУЛЯРНОСТЬ» отличается от легендарной формой/композицией, полный эффект
  («Круговая волна: новый облик. Открывает «Цепь лизиса»») и рецепт видны без
  обрезания; после выбора меняется облик и открывается условие «Цепи лизиса».
- **Трофей:** заголовок «ЛЕГЕНДАРНЫЙ ТРОФЕЙ»; подзаголовок отвечает, что в
  «Сердце» сбросится (уровень 1, прочность 100, мутации заново) и что трофей
  останется на весь забег; правило «одна из двух» под заголовком; сноска про
  лимит легендарных соответствует тому, бралась ли случайная легендарная до
  босса; на картах с подсказкой — строка «В Сердце: …» (у «ХИЩНИКА ЯДРА» —
  про элитки и КАРДИАЛЬНОМ ТИТАНЕ, у «РИТМА МИОКАРДА» — окно 850 мс и
  безопасная зона).
- Один тап выбирает; быстрый повторный тап ничего не выбирает; отпускание
  пальца за пределами карточки ничего не выбирает; после последнего выбора
  пауза снимается и бой продолжается; флаг трофея снимается, легендарная —
  применена.
- 320×568 и 390×844: предложения, блоки рецептов, условия, цена и сноска
  помещаются без обрезания. Короткий 320×520 проходит squeeze/ужимом
  (футер-декор спецкарточек убирается, копия сохраняется).

## Команды проверок (ноутбук)

```
npm run test:mutation-states        # контракт данных A/B/C + блок рецепта + QA-трофеи
npm run test:mutation-copy          # копир экрана: заголовок, форма носителя, рецепт, трофей
npm run test:mutation-before-after  # пары «было → стало» из живого состояния
npm run test:ui-copy                # пины копира каталога
npm run test:choice-integrity       # тап/повторный тап/очередь (нужен Vite :5173)
npm run test:legendary              # легендарные: пул, условия, лимит слотов
npm run test:legendary-layout       # 88 сценариев легендарок, 320×520 внутри (нужен Vite :5173)
npm run test:checkpoint             # чекпоинты
npm run test:language               # языковый гвард копира
node scripts/mutation-states-probe.cjs  # браузер: A/B/B-mid/C, QA-параметры, трофей
                                        # fresh/one/used/rhythm, тапы, церемонии, .webm
```

Проба поднимает свой Vite на :5199 (переопределить `OFELIYA_PORT`), пишет
кадры и записи в `docs/qa/mutation-states-2026-11-09/`. Долгий прогон можно
резать по размерам: `OFELIYA_SIZES=320x568` (или `390x844`). Перед прогоном
убедиться, что порт свободен — иначе возможны зависания (см. «Границы»).

## Артефакты

- `320x568/390x844-A-*` — экран A; `-A-insurance-*` — пик страховки,
  срабатывание от смертельного урона, возврат формы через 8 с
  (`-trigger-record.webm`, `-tap-and-return-record.webm`).
- `320x568/390x844-B-choice.png` — блок рецепта «последнее условие»;
  `-B-mid-choice.png` — блок рецепта в середине пути; `-B-after-pick-offer.png`
  и `-B-pick-and-offer-record.webm` — следующее предложение начинается с
  эволюции.
- `320x568/390x844-C-*` — эволюция C (`-C-evolution-pick-record.webm`).
- `320x568/390x844-TROPHY-{fresh,one,used,rhythm}.png` — трофей в четырёх
  состояниях; `390x844-TROPHY-picked-ceremony.png` и
  `-TROPHY-pick-record.webm` — выбор трофея: церемония, флаг снят, легендарная
  применена, бой продолжается.
- `report.json` — сводка пробы.

## Границы

Только экран мутаций и трофей первого босса. Шансы выпадения, перенос билда в
«Сердце», Кодекс и Коллекция — отдельные задачи. Браузерные прогоны — на
Chromium (Playwright); перед каждым прогоном порты :5173/:5199 должны быть
свободны: прерванный прогон оставляет Vite/Chrome-процессы, и следующий прогон
может зависнуть (лечится остановкой процессов `vite.js --port` и
`chrome-headless-shell`). Скриншоты и записи здесь — браузерные; телефонные —
за владельцем.
