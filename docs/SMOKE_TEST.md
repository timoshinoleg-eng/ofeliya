# OFELIYA — Smoke-тест / чеклист ручной проверки (QA)

Матрица: **iOS Safari + Android Chrome**, портрет + ландшафт, ширина от 360px
(iPhone SE/13, Pixel 4a). Внутри MAX и в обычном браузере.

> В песочнице нет headless-браузера (нет доступа к cdn.playwright.dev), поэтому
> автосмоук ограничен `npm run smoke` (логика: rng/стрики/топ),
> `npm run server:test` (сервер: валидация initData, анти-чит, топы, рефы — 16
> проверок) и `npm run build` (типы + сборка). Всё ниже — руками.
> Dev-ручка `window.__game` есть в dev-сборке (прокачка кадров:
> `__game.loop.step(t)` — при замороженном rAF в панели IAB).

## 0. Запуск

- [ ] `npm ci && npm run build` — зелёный (CI тоже).
- [ ] `npm run smoke` — ALL PASS.
- [ ] `npm run server:test` — 16 проверок пройдено.
- [ ] `npm run dev` → http://localhost:5173 — игра стартует без ошибок в консоли.
- [ ] `npm run server` (TG_BOT_TOKEN/MAX_BOT_TOKEN) → `GET /health` = ok.
- [ ] Фоны: MAX (тест-бот), Telegram (бот с Web App URL), VK/OK (mini-app) + браузер
      — старт в четырёх без ошибок в консоли.

## 1. Управление (главный приоритет)

- [ ] Джойстик появляется **строго под пальцем**, исчезает при отпускании
      (кноб плавно возвращается, не «залипает»).
- [ ] Медленное движение — плавное; резкая смена направления — без рывка
      (deadzone 0.14 + ramp).
- [ ] Тап по верхней HUD-зоне (таймер/кнопки) **не** создаёт джойстик.
- [ ] Свайп-флик (≥48px за ≤200ms) → рывок в направлении свайпа, i-frames,
      трейл+звук; повторный флик в течение 1.1s — без рывка.
- [ ] Флик **вторым пальцем** (первый держит джойстик) → тоже рывок.
- [ ] Тап по кнопкам улучшений в модалке **не** двигает игрока и не создаёт джойстик.
- [ ] Кнопки звука/паузы ≥44×44, тапаются «слепым пальцем» без случайных срабатываний.
- [ ] iOS Safari: no double-tap zoom, no pull-to-refresh, no context menu,
      no tap-highlight. Отключить «уменьшение прокрутки» не требуется (overflow:hidden).
- [ ] Notch-телефон: XP-бар/таймер не уходят за инсент; нижние кнопки не под home-indicator.
- [ ] Android Chrome: поведение то же; landscape — UI не ломается (HUD перестраивается).

## 2. Жизненный цикл

- [ ] Убрать в фон (Свайп домой) → музыка **становится тише/останавливается**,
      бой на паузе; вернуть → оверлей «ПАУЗА / продолжить».
- [ ] Пауза: «продолжить» / «заново» / «в меню» / звук — все работают; после «заново»
      забег чистый (без остатков врагов/модалок).
- [ ] MAX/Telegram: нативная кнопка «назад» в бою → пауза; повторный нажатие → закрыть паузу.
- [ ] Пауза во время модалки выбора улучшений **не** открывается (нужно выбрать карточку).

## 3. Игровой цикл

- [ ] 0:00–5:00 волны ШУМ→ИМПУЛЬС→РАЗРЫВ, элиты с 2:00 (АНОМАЛИЯ), босс ровно на 5:00.
- [ ] Босс-интро: заголовок + тряска + звук; полоса HP босса под HUD.
- [ ] Убийство босса → «ЯДРО СТАБИЛИЗИРОВАНО» (золотое свечение, частицы, вспышка).
- [ ] Смерть → «ЯДРО ПОТЕРЯНО» (красное свечение).
- [ ] Level-up: 3 карточки, прогресс-сегменты, эволюция (ПРИЗМА/ОРЕОЛ/СИНГУЛЯРНОСТЬ)
      с церемонией; очереди level-up откладываются и выдаются по одному.
- [ ] Рывок (Space/Shift на десктопе) работает.
- [ ] Combo-счётчик от ×3, сбрасывается через 2.5s.
- [ ] Milestones-баннеры (0:45/1:30/2:00/3:00/4:00) — по одному, не дублируются.

## 3b. Контент: метапрогресс и новые враги/оружие (K1/K2/K3)

- [ ] **Осколки (K1)**: после забега на game over строка «⬢ +N ОСКОЛКИ»;
      в меню кнопка «ЯДРО · ⬢ N» с актуальным балансом.
- [ ] **Мета-шоп (K1)**: тап по «ЯДРО» — модалка с 5 треками (ПУЛЬС/ОБОЛОЧКА/
      ДВИЖОК/ПОЛЕ/РЕЗОНАНС), Lv X/max, стоимость; покупка списывает осколки,
      звук+хайпик, модалка обновляется; MAX-трек — «MAX»; закрытие — крестом
      (фон) или «ЗАКРЫТЬ». После покупки: в новом забеге статы выше
      (урон/HP/скорость/магнит).
- [ ] **Сплиттер (K2)**: с ~1.5 мин зелёные ромбы; при смерти трескаются на
      2–3 мелких быстрых миньонов (зелёные точки).
- [ ] **Щитона (K2)**: с ~3 мин синие с дугой-щитом; щит повёрнут к игроку,
      пули спереди гасятся (урон ~¼, мелкие цифры), клинки/нова бьют в полную.
- [ ] **Снайпер (K2)**: с ~5 мин фиолетовые «глаза»; держат дистанцию,
      стреляют розовыми снарядами; уклонение/рывок гасит снаряд (i-frames).
- [ ] **КОМЕТА (K3)**: апгрейд «КОМЕТА» → периодически большой оранжевый
      снаряд (×урон, прожигает толпу).
- [ ] **ФОКУС-ЛЕНЗА (K3)**: пули летят заметно быстрее/дальше.
- [ ] **Эволюции K3**: ВОРТЕКС (нова засасывает + замедление), ПЕРЕГРУЗКА
      (авто-залп по кругу раз в 7 с), АЭГИС (контр-нова при попадании, 8 с).
- [ ] **Боссы (K4)**: на 5:00 один из трёх — КОРОНА (базовый), ФОРТЕЦА
      (орбитальные клинки + радиальные залпы, клинки режут при касании),
      РАЗДЕЛЯЮЩЕЕ ЯДРО (в 50% HP трескается на 2 осколка; победа — убить оба;
      HP-бар = сумма осколков). Тип daily-честный (seeded).
- [ ] **Бомбёр (K5)**: оранжевая сфера; при смерти взрыв (кольцо) — урон по
      игроку в радиусе; добивать издалека или рывком.
- [ ] **Мина (K5)**: неподвижная, пульсирует при приближении, детонирует
      вплотную или по урону; через ~25 с «разряжается» тихо.
- [ ] **Достижения (K6)**: во вкладке «ДОСТИЖЕНИЯ» мета-шопа — 11 целей с
      наградами ⬢; после выполнения ✓ (бонус в балансе); проверяется после
      каждого забега (победа/киллы/комбо/рекорды/эволюции/осколки).
- [ ] Баланс: новые враги/боссы не ломают кривую — проигрыш по-прежнему
      честен, победа за 5:00+ по боссу достижима со сборкой.

## 4. Виральные механики

- [ ] **Daily**: кнопка «ЕЖЕДНЕВНОЕ» в меню → забег с бейджем в HUD; два забега в один
      день с одинаковым сидом дают одинаковые волны/выборы (проверка на двух
      устройствах или перезагрузкой — порядок врагов одинаков).
- [ ] Стрик: забег сегодня → +1; завтра → +2; пропуск дня → сброс на 1.
      «РЕКОРД ДНЯ» — только за улучшение результата **в тот же день**.
- [ ] **Лидерборд**: топ-3 в меню, «№K в локальном топе» на game over (только K≤5),
      победа выше поражения при равном времени; макс. 10 записей.
- [ ] **Шаринг**: кнопка «ПОДЕЛИТЬСЯ» — в MAX/Telegram открывается нативный шеринг
      с карточкой (время/киллы/ядро/эволюции/рекорды/ежедневное + deep link);
      в браузере — системный share-лист → fallback «Скопировано».
- [ ] Открыть deep link (startapp=...) → в меню подсказка «ты пришёл по вызову».
- [ ] **Рефералы**: «ПРИГЛАСИТЬ» на game over → ссылка `ref_<uid>`; открыть её
      на втором аккаунте → подсказка «друг позвал»; первый забег — +1 HP
      (HUD-бар на единицу шире) и рывк быстрее (кулдаун ~0.77s);
      referrer получает push «твой ход» (TG, если задан TG_BOT_TOKEN и GAME_URL).
- [ ] Повторный забег приглашённого — бонус НЕ повторяется (refBonusUsed).

## 4a. Сервер и аналитика (включать после деплоя бэкенда)

- [ ] Забег с `VITE_SERVER_URL` → в `server/data/store.json` появилась запись
      (verified=true в TG/MAX, browser — verified=false).
- [ ] Меню: глобальный топ-3 появляется (✈/✉/🖥) при живом сервере;
      при мёртвом — без него, без ошибок в консоли.
- [ ] Счёт «чехлом» (консоль: fetch /api/score с чужим timeMs=1e9) → 422,
      в store не попадает.
- [ ] Аналитика: без `VITE_ANALYTICS_URL` события копятся в localStorage
      (`ofeliya_analytics_buffer`); с URL — уходит POST на endpoint, буфер очищается.

## 4b. VK Mini Apps / OK (V6) — проверять внутри VK/OK-клиента

- [ ] Старт в VK (мобильный + веб vk.com) и в Одноклассниках: fullscreen,
      игра работает, шапка VK скрыта (VKWebAppRequestFullscreen).
- [ ] Приветствие «Привет, <имя>!» в меню (имя из VKWebAppGetUserInfo).
- [ ] Deep link (реф): открыть `?ref_<uid>` / start_param → подсказка «друг позвал»

- [ ] «ПРИГЛАСИТЬ»/«ПОДЕЛИТЬСЯ» → нативное VK-окно шеринга (VKWebAppShowShareBox).
- [ ] Rewarded (если задан `VITE_VK_REWARD_PLACEMENT_ID` и есть инвентарь):
      в паузе кнопка «СМОТРЕТЬ РЕКЛАМУ: +1 HP» → досмотр → +1 HP (HP-бар +1);
      закрыть досрочно → без бонуса; лимит 3/забег (кнопка исчезает).
- [ ] Без placement_id / вне VK / нет рекламы — rewarded-кнопки НЕТ (не ломает меню).
- [ ] VK-скор уходит на сервер как unverified (platform=vk, в shadow-топе, не в общий топ).
- [ ] Обычный браузер (не VK): kind=browser, игра как раньше, vkBridge не мешает.

## 4c. Соц-топ / сезон / клип (V2, V4, C5, V5)

Сервер и клип — включать после деплоя бэкенда; клип проверяется на реальном
устройстве (MediaRecorder/captureStream в webview могут отсутствовать → тогда
кнопка шаринга делит карточку, это корректное фолбэк-поведение).

- [ ] **Топ друзей (V2)**: А приглашает Б (открыть `ref_<uid>` А у Б); Б
      завершает забег; на game over у А блок «ДРУЗЬЯ» → строка Б (`···123`,
      метка «ты позвал»), у Б → метка «позвал». uid анонимизирован (только хвост).
- [ ] **Сезон (C5)**: меню — бейдж «🏆 СЕЗОН N · M дн до конца» (M>0);
      глобальный топ-3 в меню — сезонный (только скоры текущего окна).
      `GET /api/season` → `{index, start, end, daysLeft}`.
- [ ] **Результат дня (V4)**: завершить daily-забег → на game over строка
      «📅 СЕГОДНЯ: №N из M» (N=место, M=участников дня). Обычный забег — строки НЕТ.
- [ ] **Клип (V5)**: победа → «ПОДЕЛИТЬСЯ» открывает системный share-лист с
      видео-файлом (webm/mp4, ~12 с последних секунд). Не поддержано/отмена →
      фолбэк на карточку (текст+ссылка). Проигрыш → сразу карточка.
- [ ] **Клип-регресс**: на устройстве без MediaRecorder (старый webview) игра
      работает, FPS не проседает (preserveDrawingBuffer отключён), шаринг = карточка.
- [ ] Сервер: `GET /api/daily?user=&platform=` и `GET /api/friends?user=&platform=`
      → 200 + `ok:true`; при пустом `user` → 400.

## 4d. MAX / Android — портрет и twin-stick (M-блок)

Проверять на вертикальном экране (MAX-мессенджер, Samsung C20+, ~360×780 CSS px)
и в DevTools-эмуляции портрета.

**Портретная вёрстка (ничего не обрезано / не наезжает):**
- [ ] Меню: вертикальный flow — заголовок, слоган, приветствие, рекорды,
      «ежедневное», ЗАПУСТИТЬ ЯДРО, ряд (ЕЖЕДНЕВНОЕ / ЯДРО / звук),
      кнопка управления, лидерборды, how-to, версия — ничего не перекрывается.
- [ ] Меню: текст daily-строки переносится (wordWrap), а не уходит за край.
- [ ] HUD в бою: XP-бар, таймер, «ЯДРО N», «ОЧИЩ. N», HP, mute/pause — видны
      под notch (SafeArea.top учтён), джойстик не появляется под HUD-полосой.
- [ ] Level-up модалка: 3 карточки помещаются (компактные размеры), текст
      переносится, кнопки-карточки нажимаются.
- [ ] Game over: заголовок, время, статы, эволюции/сборка, достижения, daily,
      топ-5, осколки + 4 кнопки (ЕЩЁ РАЗ / ПОДЕЛИТЬСЯ / ПРИГЛАСИТЬ / В МЕНЮ)
      — все видны, нижняя кнопка не уходит за home-indicator.
- [ ] Pause-модалка и rewarded-бонус (VK) читаемы в портрете.

**Управление — режим «1 палец» (дефолт, casual):**
- [ ] Плавающий стик движения под пальцем, флик (быстрый свайп) → уклонение.
- [ ] Стрельба — авто-прицел по ближайшему врагу (без второго пальца).
- [ ] Режим переключается кнопкой «🕹 1 ПАЛЕЦ · АВТО-ПРИЦЕЛ» в меню.

**Управление — режим «2 пальца» (twin-stick, скоростной):**
- [ ] Левая половина — стик движения (циан); правая — стик прицела (золото).
- [ ] Удержание правого стика за dead-zone → огонь в ЕГО направлении (manual).
- [ ] Правый стик в dead-zone / отпущен → возврат к авто-прицелу (aim-assist).
- [ ] Флик → уклонение только с ЛЕВОЙ половины (правая — прицел, без рывков).
- [ ] Режим переключается на «🕹 2 ПАЛЬЦА · ТВИН-СТИК», персистится в SaveSystem,
      действует со следующего забега; analytics `control_mode_changed`.
- [ ] Intro-hint в twin-stick объясняет зоны (левая/правая половина).
- [ ] Зоны sticky: палец, начатый в левой половине, не «перескакивает» в
      прицел при пересечении середины экрана.

## 5. Производительность

- [ ] Chrome DevTools → Performance: записать 10с позднего боя (4:30+, толпа):
      frame time стабильно ≤16.7ms (60 FPS) на среднем телефоне; при просадке
      bloom автоматически отключается (видимо: чуть «суше» картинка + виньетка-текстура).

- [ ] Late-game: 200+ врагов на экране — FPS держится (пулы, cap 240).
