# GAME LANGUAGE BIBLE — канонический словарь OFELIYA

Волна 1 «language foundation». Источник истины для всего игрок-видимого текста.
Внутренние идентификаторы (id врагов, сложностей, боссов, ключи хранения) **не меняются** —
канонизируется только слой отображения.

## 1. Принципы

1. **RU-first.** Игровой текст — русский. Английский допускается только как вторичный
   эпитет брендовых имён (боссы, продукт) и в именах собственных платформ (MAX, Telegram).
2. **Без внутренних терминов.** Идентификаторы реализации (id, пулы, окна, версии правил)
   никогда не показываются игроку. Полный список — §3.
3. **Точные числа.** Любое переписывание описаний сохраняет числа и семантику механик 1:1.
4. **Первое употребление объясняется.** Термин вводится короткой расшифровкой в месте
   первого появления (примеры — §4) либо живёт в КОДЕКСЕ.
5. **Имя продукта** — `OFELIYA`, protagonist code name — `STRAIN-0`. Переименование —
   отдельное gated-решение, в этой волне не выполняется.

| Было | Канон |
|---|---|
| `RULESET vN · #rank` | **РЕЙТИНГ · МЕСТО #N** |
| `CHECKPOINT RESUME` | **ЗАБЕГ ВОЗОБНОВЛЁН** |
| `FIXED-SEED DUEL` | **ДУЭЛЬ** |
| `STANDARD/STRAINED` (латиницей) | **СТАНДАРТ / НАПРЯЖЕНИЕ** |
| `ИММУНИТЕТ: N · Клеток: M` | **УНИЧТОЖЕНО: N · Заражено: M** |
| ` Legendary:` (share) | **Легендарные:** |
| заголовки | **ИММУНИТЕТ ПОДАВЛЕН / ШТАММ УНИЧТОЖЕН** |
| режим ежедневного забега | **РЕЖИМ: СТАНДАРТ · ежедневный забег** |
| ежедневный результат принят | **ЕЖЕДНЕВНЫЙ ЗАБЕГ · РЕЗУЛЬТАТ СОХРАНЁН** (с местом: **ЕЖЕДНЕВНЫЙ ЗАБЕГ · #N СРЕДИ ИГРОКОВ СЕГОДНЯ**) |
| ежедневный результат не синхронизирован | **ЕЖЕДНЕВНЫЙ ЗАБЕГ · РЕЗУЛЬТАТ НЕ СИНХРОНИЗИРОВАН** |
| окно ежедневного результата | **ЕЖЕДНЕВНЫЙ ЗАБЕГ · ОКНО РЕЗУЛЬТАТА ЗАКРЫТО** / **ЕЖЕДНЕВНЫЙ ЗАБЕГ · ВРЕМЯ РЕЗУЛЬТАТА ИСТЕКЛО** |
| ежедневный запуск без подтверждения | **ЕЖЕДНЕВНЫЙ ЗАБЕГ · НУЖЕН ПОДТВЕРЖДЁННЫЙ ЗАПУСК** |
| ежедневный сервис недоступен | **ЕЖЕДНЕВНЫЙ ЗАБЕГ · СЕРВИС НЕДОСТУПЕН** / **ЕЖЕДНЕВНЫЙ ЗАБЕГ · ПРОВЕРЬТЕ СОЕДИНЕНИЕ** |
| ежедневная идентичность | **ЕЖЕДНЕВНЫЙ ЗАБЕГ · НУЖНА ИДЕНТИЧНОСТЬ МЕССЕНДЖЕРА** |
| запуск из СВОДКИ | **НАЧАТЬ ЕЖЕДНЕВНЫЙ ЗАБЕГ** / **ПОЛУЧАЕМ ЕЖЕДНЕВНЫЙ ЗАБЕГ…** |
| временная ёмкость запуска | **ЗАБЕГ НЕДОСТУПЕН · ПОВТОРИТЬ** |
| ошибка запуска | **СЕРВЕР НЕ ОТВЕТИЛ · ПОВТОРИТЬ** / **НЕТ СОЕДИНЕНИЯ · ПОВТОРИТЬ** |
| запуск без messenger identity | **НУЖЕН ВХОД ЧЕРЕЗ MAX ИЛИ TG** / **НУЖЕН ПОДТВЕРЖДЁННЫЙ ВХОД** |

> **Ежедневный забег никогда не выводит глобальные рейтинговые семантики.**
> Строка режима показывает `ежедневный забег` вместо `рейтинговый`, а место —
> только в формате ежедневного статуса (`#N СРЕДИ ИГРОКОВ СЕГОДНЯ`), но не как
> глобальную строку `РЕЙТИНГ · МЕСТО #N`. Вознаграждения не заявляются; обычные
> личные записи и достижения ежедневного забега при этом обновляются.

`Core Window`, `host cell(s)`, `enemy pool`, `projectile pool`, `swarm`, `elite`,

`STANDARD`/`STRAINED` латиницей, `Codex`, `LEGENDARY`, `Fixed-Seed`, `Pre-release`,
`npm run *`.

Автоконтроль: `npm run test:language` (scripts/check-language-copy.mjs) — статически
сканирует строковые литералы игрок-видимых модулей. В юридическом оверлее
(`src/legal/LegalOverlay.ts`) допустима операторская заметка со ссылкой на
команду сборки — она не является игровым текстом.

## 4. Примеры первого употребления

- **РНК:** «Собирай фрагменты РНК — ускоряешь следующую мутацию».
- **ПУЛЬС:** «В СЕРДЦЕ лови паузу между ударами пульса — в это время иммунитет слабее».
- **УЯЗВИМОЕ ЯДРО:** «Четыре последовательных попадания открывают уязвимое ядро
  на 1,5 секунды; по ядру урон +75%».
- **ЛИЗИС:** «Лизис — разрыв заражённой клетки: даёт РНК и бьёт по соседям».
- **ЛЕГЕНДАРНАЯ МУТАЦИЯ:** «Легендарная мутация меняет правила забега; максимум две за цикл».

## 5. Канон-шаблон карты мутации

```
[СЕМЬЯ] · [РЕДКОСТЬ]
ИКОНКА  КОРОТКОЕ ИМЯ        ← ≤2 строки
        ТОЧНЫЙ ЭФФЕКТ       ← цифры обязательны
        [→ КРИТ. МУТАЦИЯ]
        ▮▮▮▯▯▯ 3 → 4 / 6
```

Редкость: `СТАНДАРТ / РЕДКИЙ / КРИТИЧЕСКАЯ / ЛЕГЕНДАРНАЯ`.
Семейства: `АГРЕССИЯ · РАСПРОСТРАНЕНИЕ · ЗАЩИТА · АДАПТАЦИЯ`.

```
ЗАГОЛОВОК:   ИММУНИТЕТ ПОДАВЛЕН / ШТАММ УНИЧТОЖЕН
ВРЕМЯ:       MM:SS
СТАТИСТИКА:  УНИЧТОЖЕНО: N · Заражено: M · Пик мутации: L · Комбо ×C
ДЕТАЛИ:      Крит. мутации · Легендарные · Штамм по актам · Режим
РЕЙТИНГ:     РЕЙТИНГ · МЕСТО #N  |  ЗАБЕГ ВОЗОБНОВЛЁН · ВНЕ РЕЙТИНГА
CTA:         ЕЩЁ ОДИН ЦИКЛ | ПОДЕЛИТЬСЯ / ВЫЗОВ / ДУЭЛЬ | В МЕНЮ
```
