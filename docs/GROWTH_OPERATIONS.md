# OFELIYA — Операции роста (C1)

Операционный ранбук для команд, которые ведут трафик и retention после релиза.
Цифры — из [RESEARCH_AND_PLAN.md](RESEARCH_AND_PLAN.md) §1.4/§1.5 (MAX-цены 2026,
VK Ads, бенчмарки GameAnalytics). Цель — держать CAC ниже LTV и не терять
retention (kill-сигналы ниже).

## 0. Цель и главная метрика (north star)

- **North star**: `D7 ≥ 12–15%` и `D30 ≥ 5–7%` при `share ≥ 8%` (90 дней, 10k DAU).
- **Kill-сигналы** (стоп/разворот бюджета): `D1 < 22%` или `D7 < 4%` —
  качество падающего трафика ниже медианы рынка → чинить оффер/креатив, а не
  заливать больше.
- **CAC-потолок**: < 500 Stars (≈ рублёвый эквивалент) на активного D7-игрока.

## 1. Роли и такт

| Роль | Что делает | Такт |
|---|---|---|
| **Growth-оператор** | Каналы, бюджеты, запуски посевов, A/B креативов | ежедневно |
| **Аналитик** | Воронки D0/D1/D7/D30, когортные retention, LTV, анти-чит-аномалии | еженедельно + alert |
| **Контент** | Креативы (иконка, 30-с клип, playable), A/B-варианты | 2/нед |
| **Комьюнити** | Ответы в TG/VK-ботах, топ-игроки, стрики-челленджи | ежедневно |

**Еженедельный ревью (30 мин)**: D1/D7/D30 по когортам, CAC по каналу,
share-коэффициент, kill-сигналы, один эксперимент → решение (scale/kill/iterate).

## 2. Каналы и бюджеты (фаза 1: MAX + браузер)

Приоритет — дешёвый вход и органика, до платного масштабирования.

| Канал | Цена | Мин. бюджет | Тактика |
|---|---|---|---|
| **Органика MAX** (каталог мини-аппов, бот) | 0 | 0 | База. Оптимизация карточки (иконка, описание, скриншоты). |
| **Посевы в MAX-каналах** | 50–70 ₽/подп. | 10–30k ₽/нед | Посевы в игровых/казуальных каналах; реф-ссылка в каждом посеве (для атрибуции). |
| **Авито** | 2–3 ₽/клик | по кликам | Самый дешёвый платный вход; ссылка на мини-апп/веб. |
| **VK Ads (таргет на MAX)** | 50–90 ₽/подп. | от 30k ₽ | Только после валидации retention; аудитория — фанаты казуальных игр. |
| **Яндекс Директ (кликаут)** | 60–120 ₽ | от 30k ₽ | Подпись на бота/веб; brand+кейворды. |
| **Referred (рефералы)** | 0 (бонус игрокам) | 0 | Встроенный вирус: «ПРИГЛАСИТЬ» + бонус + push «твой ход». |

**Правило M**: платим только за косметику/convenience внутри игры (никаких
pay-to-win) — иначе retention обваливается.

### Атрибуция
- Каждый платный канал → **уникальная реф-ссылка** (`ref_<tag>`) → сервер
  фиксирует рёбро → `source` в когорте. В MAX/TG deep link `startapp=ref_<tag>`.
- Анализируем D1/D7/CAC по `source`, а не в среднем.

## 3. Запуск (по неделям)

- **Неделя 1 (мягкий старт)**: органика MAX + TG-бот + 2–3 посевы (20–30k ₽)
  в тематических каналах + Авито-тест. Цель: первая когорта, проверить D1≥30.
- **Неделя 2**: A/B креативов (2 варианта иконки/описания), масштаб победителя.
  Включаем реферал-механику (пуш «твой ход»). Цель: share≥8%, D1≥30.
- **Неделя 3**: VK Mini Apps (каталог + Deploy) — вторая дистрибуция.
  Rewarded-реклама (монетизация). Цель: D7≥12, CAC<500.
- **Неделя 4+**: VK Ads / Директ при D7 в норме. Сезон (C5) для retention.
  Playable-креатив из 30-с клипа победы.

## 4. Ретейн-инструменты (что уже в игре)

- **Daily challenge** (сид от даты) + стрики → D1/D7.
- **Сезон (C5)** (14 дней) → D30, возвращение на новый сезон.
- **Рефералы (V1)** + бот-пуш «твой ход» (V7) → возвратные касания.
- **Топ друзей (V2)** → социальное сравнение.
- **Achievements/рекорды** → микро-цели.

Оператор следит: стрик-когорта (сколько вернулись на D2+), реферальный коэффициент,
сезон-возврат.

## 5. Трекинг (связка с аналитикой R1)

События уже в `Analytics.ts` (PostHog-совместимые + VKWebAppTrackEvent).
Дашборд (PostHog / VK Ads) по этим событиям:

| Метрика | События |
|---|---|
| Активация | `open`, `first_run`, `run_started` |
| Retention D0/D1/D7/D30 | `open` по дням (когорты) |
| Завершение забега | `run_completed` (win/timeMs/kills/level/daily) |
| Вирусность | `share_opened`/`share_done`, `ref_shared`/`ref_opened` |
| Монетизация (VK) | `reward_ad_opened`/`reward_ad_done` |
| Воронка | `open → run_started → run_completed → share_done` |

**Alert'ы** (автоматически): D1 < 22%, D7 < 4%, share < 5%, скачок 422
(анти-чит) — сигнал о ботах.

## 6. Креативы (чек-лист)

- [ ] Иконка 512 (уже есть: `public/icons/icon-512.png`) + A/B-вариант.
- [ ] 30-сек вертикальный клип победы (для playable-рекламы/посевов).
- [ ] 3 скриншота: меню, поздний бой (толпа), game over со статистикой.
- [ ] Описание карточки: что за игра, 3 буллета, CTA «Играть».
- [ ] Reel/тикток-фрагменты «почти победил» (для посевов).

## 7. Риски и стоп-краны

- **Боты/антиспам**: серверный анти-чит (422) + unverified-тень для web/VK;
  alert на скачок 422 → чистим топ.
- **Дорогой трафик без retention**: kill-сигнал → стоп бюджета, чиним оффер.
- **Лимиты платформ**: модерация VK до 7 дней; бюджет VK Ads от 30k ₽ —
  планируем заранее.
- **Зависимость от одного мессенджера**: MAX + TG + VK + браузер — диверсификация.
