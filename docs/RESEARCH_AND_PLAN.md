# OFELIYA — исследование и план (v0.3 + продвижение)

Дата: 2026-09-10. Задача: глубокий поиск проектов, которые усиливают игру,
и план улучшения/продвижения. Источники — ссылки в конце; коды с лицензиями,
не совместимыми с правилами проекта (только MIT/CC0/OFL/ISC/Apache-2.0), отклонены.

---

## 1. Что найдено

### 1.1. Контекст платформ (где играть и как дистрибуция)

**MAX (VK)** — основной рынок проекта:
- 125M+ зарегистрированных, DAU 77–85M (2026), **обязательная предустановка**
  на все новые устройства РФ с 09.2025, 3.6M каналов. Мини-приложения — HTML/JS
  через бота (MAX Bridge + React-кит MAX UI); платежи — СБП.
- «Платформа для партнёров» (RuStore-паблишеры) открыта с 10.2025 → канал
  публикации и продвижения игровых мини-аппов через партнёрку.
- Рынок игровых мини-аппов в MAX почти пуст (ранняя фаза) — окно первой волны:
  кто первым займёт нишу «аркадные мини-игры», получает сетевой эффект.

**Telegram**:
- 500M+ пользователей мини-аппов ежемесячно; с 12.2025 работает **Mini App
  Store** (вкладка «Apps» в поиске): сабмит с видео-демо и скриншотами →
  органическая витрина.
- **Stars**: IAP внутри TG; 7% lifetime-affiliate на траты приглашённых.
- Rewarded-реклама (AdsGram, PropellerAds, RichAds, Monetag): CTR 20–40%
  (против 0.5–2% у классических баннеров) — базовый монетизационный слой.
- Каналы TG: native-посты CPM ~0.1 TON (против ~$17 в Facebook-подобных сетях).

**Вывод:** дистрибуция у нас уже есть (двойной мост MAX+TG + браузер).
Дорог нет в коде — дороги в витринах (TG Mini App Store, партнёрка MAX) и
в виральном цикле внутри игры.

### 1.3. Открытый код, который усиливает проект

| Проект | Лицензия | Как применить |
|---|---|---|
| **PocketBase** (github.com/pocketbase/pocketbase) | MIT | Один Go-бинарник: БД + auth + realtime + API. Сервер для: валидации initData (HMAC), score-подачи, daily-состояния, рефералов. Разворачивается на VPS за $5. **Рекомендуемый бэкенд** |
| **LEADR** (github.com/LEADR-official/leadr-oss) | Apache-2.0 | Готовый self-hosted лидерборд: **anti-cheat, сезонные/ежедневные доски, архив**. Альтернатива/дополнение PocketBase, если нужен только топ |
| **Nakama** (Heroic Labs) | Apache-2.0 | Полный игровой сервер (auth, leaderboards, matchmaking). Тяжелее, чем нужно сейчас; смотреть при мультиплеере |
| **Talo** | MIT | Инди-бэкенд с бесплатным тиром (10k игроков) — запасной вариант, если не хочется self-host |
| **phaser3-vjoy-plugin** | MIT | Внешний джойстик. **Не берём** — наш Joystick v2 функциональнее (flick-dodge, ramp-deadzone); оставляем свой |
| **Plausible / PostHog** (self-host) | AGPL/MIT | Атрибуция: события-воронка (open → first_run → 5min → share), DAU, D1/D7 retention. PostHog — с продуктовыми дашбордами; Plausible — легче. Для старта: 10 событий в PostHog |
| **canvas-vampire-survivors** | MIT | **PWA-паттерн** (manifest + service worker, «Add to Home Screen», offline) — переносим идею в OFELIYA (vite-plugin-pwa) |
| **Kenney CC0** (доп. паки) | CC0 | Косметика: иконки, UI-фреймы, пиксельные пак для операторов/трейлов; 60k+ ассетов, zero license risk |
| **Freesound / OpenGameArt CC0** | CC0 | Музыкальное разнообразие: 3–5 новых CC0-треков (перекликающиеся с текущими 7), доп. SFX-текстуры |
| **max-ui / MAX Bridge** | — (доки VK) | Уже интегрирован; следить за обновлениями API (getViewportSize, themeParams, shareContent) |

**Лицензионная гигиена:** GPL-кода в зависимостях нет; PostHog self-host — AGPL,
но AGPL-сервер не смешивается с клиентским MIT-кодом игры (это отдельный сервис,
не библиотека) — риск «открытия исходников игры» отсутствует. Если AGPL не
удобно — Plausible (AGPL тоже) или свой мини-коллектор на PocketBase (MIT).

## 2. План улучшения (v0.3)

Приоритеты: **retention → виральность → контент → монетизация**. Каждое — с
критерием готовности. Оценка — условные дни работы одного разработчика.

### 2.1. Ретеншн и данные (неделя 1–2, ~5 дн.)

| # | Что | Зачем | Критерий |
|---|---|---|---|
| R1 | **Аналитика** (PostHog self-host или 10 событий в PocketBase): `open`, `first_run`, `run_completed(win)`, `dodge_used`, `share_opened`, `share_done(channel)`, `daily_done`, `ref_opened`, `pause_shown`, `exit_at_menu` | Без данных не видно, где теряет | Дашборд: DAU, D1/D7 retention, конверсия share |
| R2 | **PWA**: manifest + service worker (vite-plugin-pwa), offline-заглушка, иконка | «Add to Home Screen» → D7 retention на 20–40% выше (бенчмарки TG-games) | Установка с телефона, перезапуск офлайн показывает menu |
| R3 | **Дневные награды/миссии** (лёгкий слой поверх daily): 3 ежедневные микрозадачи (сыграть daily, 3 рывка за забег, обновить рекорд дня) → бонус (лечилка/XP) | Hamster-паттерн «вернуться сегодня» | Задачи видны в меню, награда начисляется, прогресс виден |
| R4 | **Onboarding-фидбек**: тост «+XP», первый dodge подсвечивается hint'ом, win/lose-экран показывает «почему» (причина смерти: HP 0 на X-мин) | Первые 30 секунд = отток | D1 retention растёт (из R1) |
| R5 | **Настройки**: качество графики (auto/high/low — уже есть auto, добавить ручной тумблер), язык RU/EN (IDENTITY.copy → i18n-обёртка) | Доступность | Переключатели в меню, выбор персистится |

### 2.2. Виральность (неделя 2–3, ~6 дн.)

| # | Что | Зачем | Критерий |
|---|---|---|---|
| V1 | **Рефералы**: deep link `startapp=ref_<id>_<run>`; при открытии по рефу — обеим сторонам одноразовый бонус (первой сессии: +1 лечилка / −30% кулдаун рывка); кнопка «ПРИГЛАСИТЬ ЯДРО» в game over; баннер «результат друга N — твой ход?» | Не P2E, а социальное FOMO: друг показал результат → ты заходишь ответить | Ref-счётчик в аналитике, бонус выдаётся один раз |
| V2 | **Топ друзей** (нужен бэкенд): топ-100 глобальный + «твои друзья» (TG/MAX user ID из initData); еженедельный сброс | Соревнование с друзьями = лучший retention-драйвер | Раздел в меню, обновление раз в неделю |
| V3 | **Бэкенд** (PocketBase, MIT, один бинарник на VPS): `POST /score` с валидацией initData (HMAC: MAX — токен бота, TG — токен бота), anti-cheat: проверка `score ≤ time*max_kill_rate`, дедупликация по userId+dateKey | Доверенные рейтинги + защита от ботов | Ложный score отклоняется, добросовестный — в топ |
| V4 | **Результат дня «общий»**: daily-топ дня (все игроки, одинаковый сид) — «ты №7 из 412 сегодня» | Сравниваемость результатов (уникальное преимущество daily) | Строка на game over + в меню |
| V5 | **Шеринг-видео**: 30-сек. вертикальный клип победы (записывается на устройство: MediaRecorder canvas.captureStream) — не обязательно, опционально | KOC-контент изнутри игры | Кнопка «Снять клип» (если MediaRecorder доступен) |
| V6 | **VK Mini Apps адаптер**: расширить MessengerBridge (vk-bridge): init, user, share, rewarded-ads (VK Bridge), VK ID; публикация в каталог vk-miniapps.com + VK Mini Apps Deploy | +1 экосистема (45M MAU) с готовой rewarded-монетизацией; VK-кейсы показывают 7M ₽/мес для игр | Игра запускается в VK/OK, share работает, rewarded-слот отдаёт бонус |
| V7 | **Бот-обвязка** (grammY, MIT; TG + MAX Bot API): startapp-deep links, реф-база (кто кого позвал), push: «N обновило твой результат — твой ход», бадж «у тебя есть награда за стрик» | Возвратные пуши — главный retention-инструмент после daily; реферал-цепочка видна с сервера | Push доставляется, реф-граф в БД, deep link открывает нужный экран |

### 2.3. Контент-глубина (неделя 3–5, ~8 дн.) — replay value

| # | Что | Зачем | Критерий |
|---|---|---|---|
| C1 | **Операторы** (Brotato-паттерн): 4 персонажа-ядра с trade-off: «ЗАСЛОН» (+i-frames, −скорость), «РЕЗОНАТОР» (+урон, −HP), «ИМПУЛЬС» (+скорость рывка, −урон), «ЯДРО-0» (базовый). Разблокировка: вайны/achievements, **не деньги** | Replay: каждый оператор = новый билд | Выбор в меню, статы применяются, разблокировки видны |
| C2 | **Шоп в конце забега** (Brotato): «остатки данных» (киллы → очки) → 1 случайное улучшение или лечилка; **crate-дроп** (реже — редкий тринкет: «магнит XP», «+1 к уровню в начале») | Дофамин лута + «ещё один забег» | Шоп на game over, предметы в сейве |
| C3 | **Третье базовое оружие** («ОРБИТАЛЬНАЯ СЕТКА» — статические ретикулы, наносящие урон проходящим) + 2 новые эволюции (итого 3×2) | Разнообразие билдов | Новый паттерн в луже врагов, эволюция в списке |
| C4 | **Еженедельный режим** (сид от недели, топ недели с косметической наградой) | Второй соревновательный слой поверх daily | Отдельная кнопка/секция, топ в меню |
| C5 | **Сезон (месяц)**: free-трек (cosmetics: трейл игрока, палитра HUD, скин босса) за события (daily×N, победы, киллы); **косметика** из Kenney-пиков/процедурной | Удержание на месяцы, валюта — не деньги, а время | Сезон в меню, награды персистятся |
| C6 | **Long run** (15:00, «ГЛУБИНА»): усиленный босс-финал + элиты-стаи | Для хардкорников/видео-контента | Режим в меню, свой счёт в топах |
| C7 | **Языки RU/EN** (вынесение строк в IDENTITY.copy/i18n) | Расширение аудитории | Переключатель в настройках |
| C8 | **Аудио-расширение**: 3–5 CC0-треков (Freesound/OGA) по фазам, глитч-амбиент босса | Атмосфера, «скриншот-моменты» со звуком | Трек-рандомер по фазе, не зацикливает |
| I1 | **itch.io-публикация** (браузерная версия): HTML5-ZIP, embed, теги, devlog; «играть в браузере» в share-карточке | Канал вне мессенджеров, KOC-вход, A/B-тест UI без модерации | Страница live, devlog ≥1/нед. в фазе 2 |

### 2.4. Монетизация (опциональный слой, после R/V, ~4 дн.)

| # | Что | Зачем | Критерий |
|---|---|---|---|
| M1 | **Rewarded ads** (AdsGram для TG; для MAX — партнёрская реклама MAX, если появится): за рекламу → +1 лечилка, ×2 XP в следующем забеге, +30с рывка; **мягкий paywall в день 0** | Benchmarks: rewarded CTR 20–40%; IAP 30–40% выручки игр | 3 слота на rewarded, без принуждения |
| M2 | **Battle pass = сезон C5** (free + premium за Stars/СБП): косметика | Модель Survivor.io | Трек с тиками, premium-слоты |
| M3 | **Revive** (1× за забег, после смерти до босса): бесплатно раз в неделю / за рекламу / за Stars | Классика survivor-монетизации | Кнопка на death-экране, лимит в сейве |

> Правило: **деньги не за силу** (no pay-to-win) — только за косметику и
> convenience. Иначе рушится соревновательность daily/топов.

## 3. План продвижения

Цель 90 дней: **10k DAU (MAX + TG + VK), D1 ≥ 30%, D7 ≥ 12–15%, D30 ≥ 5–7%,
share rate ≥ 8%** (калибровка по бенчмаркам GameAnalytics/Sensor Tower — см. 1.5:
это верх casual-рынка, а не заоблачная цель).

### Фаза 0 — подготовка витрин (неделя 1, параллельно с R1–R2)

1. **TG Mini App Store**: сабмит (видео-демо 15–30с победы + 3 скриншота:
   меню/бой/босс/топ). Витрина в поиске TG — органический трафик.
2. **MAX**: подключение к «Платформе для партнёров» (RuStore-паблишер),
   карточка мини-аппа у бота; иконка + описание с CTA «5 минут — ядро».
3. **Контент-набор**: 30-с вертикальный геймплей-ролик (победа + босс-интро),
   3 скриншота «до/после», GIF-лонгрид (флик-рывок), пост-описание
   «своими словами».
4. **Аналитика (R1)** — до запуска рекламы: иначе не измерим CAC/retention.

### Фаза 1 — soft launch (недели 2–3)

- Круг друзей + 3–5 своих каналов; тег #миниигры.
- **5–10 каналов мини-игр** (native-посты, CPM ~0.1 TON): целевые —
  TG-гейминг, TG-экономии/Stars, «игры в телефоне». Формат: «выживи 5 минут
  против узлов — daily-рейтинг».
- **Микро-инфлюенсеры** (5–20k подписчиков) в гейминг/тп: 3–5 постов +
  short-видео. Чек-лист для них: daily-челлендж + топ-день + share-карточка.
- MAX-каналы (посевы **50–70 ₽/подписчик**, vs 120–150 ₽ в TG): 5–10 каналов,
  тестовый бюджет 10–15k ₽; **Авито Реклама** (2–3 ₽/клик) — самый дешёвый
  платный вход в воронку (кликаут на канал/бот).
- KPI: CAC < 500 Stars (~$5) в юзер, **D1 ≥ 30%** (медиана рынка 22% — выше неё = ок),
  share rate ≥ 5%.

### Фаза 2 — виральный цикл (недели 3–6)

1. **Daily-челлендж-маркетинг**: еженедельный «пост-вызов» в каналах:
   «Сегодняшний сид: 09.12. Покажи свой результат» — deep link с датой.
   Дневная публичность создаёт FOMO (модель Notcoin-задач).
2. **Рефералы (V1)**: «пригласи ядро» — обоим бонус; топ-рефереров недели —
   в общий топ (социальный статус).
3. **KOC/стримы**: short-видео «10 минут — побил daily»; отправка
   share-карточки (V5) — готовый вертикальный формат.
4. **Telegram Ads** (после подтверждения unit-экономики): CPM 0.1 TON,
   таргет «игроки мини-аппов».
5. KPI: виральный коэффициент K = (share × open × D7) ≥ 0.3; DAU рост 10–20%/нед;
   kill-signal: D7 < 4% (медиана рынка) — возвращаемся к onboarding/loop.
6. **VK-расширение (V6)**: публикация в каталог VK Mini Apps (модерация до 7 дней),
   VK Mini Apps Deploy для хостинга, rewarded-слоты через VK Bridge,
   VK Ads — playable-креатив из 30-с клипа (тренд 2025: доля playable 6.3→13.3%).
7. **itch.io (браузерная версия)**: HTML5-ZIP + embed + 10 тегов; ссылка
   «играть в браузере» в share-карточке; devlog как контент для фазы 2.

### Фаза 3 — масштаб и удержание (недели 6–12)

1. **Сезон 1 (C5)**: анонс в каналах; free-трек + косметика;
   «сезонный топ» с наградами.
2. **MAX-эксклюзивные механики** (если партнёрка даёт): промо-коды через
   бота MAX, интеграция с VK-аудиторией.
3. **Кросс-промо** с другими TG/MAX-играми (мута-посты, общие чат-боты).
4. **Локализация EN** (C7) → TG-аудитория вне РФ (EN-first).
5. KPI: 10k DAU, D7 ≥ 25%, eRPC ≥ 0.5 (если включена монетизация).

### Каналы и форматы (сводка)

| Канал | Формат | Бюджет (стартовый) |
|---|---|---|
| TG Mini App Store | сабмит + обновляемые скриншоты | $0 |
| MAX Платформа партнёров | карточка + промо-коды | $0 (вход в партнёрку) |
| Каналы TG (5–10) | native-посты | 200–500 TON/мес |
| Микро-инфлюенсеры | пост + short | 100–300 TON/шт |

| Кросс-промо | мута-посты | $0 |

### Метрики-воронка (что следить по неделям)

```
open → first_run → run_5min → share → ref_open → D7
       (отток)      (retention)  (K)     (реферал) (retention)
```
Red flags: first_run < 70% (onboarding), share < 3% (карточка не цепляет),
D7 < 15% (нет возврата — включать R3/V2 раньше).

## 4. Риски и как их гасим

| Риск | Гашение |
|---|---|
| MAX API меняется/ограничен (ранняя платформа) | MessengerBridge уже абстрагирует; TG — независимый рынок; браузерный fallback |
| AGPL-зависимости (PostHog/Plausible self-host) | Это отдельный сервис, не библиотека игры; или свой мини-коллектор на PocketBase (MIT) |
| Анти-чит в топах | серверная валидация initData + score-пороги (V3); daily-топ защищён сидом (репроducible) |
| Монетизация «за силу» убьёт соревновательность | Правило: деньги только за косметику/convenience |
| Один разработчик — узкое место | Приоритеты: R1→R2→V3→V1/V2→C1; контент (C2–C6) — модульно |
| Конкуренция: крупные entrants в MAX-games | Окно ранней фазы (1–2 квартала); зафиксировать нишу «survivor + daily + топ» |

## 5. Первые шаги (на этой неделе)

1. **R1** — 10 аналитических событий (PostHog или PocketBase-эндпоинт). 1 дн.
2. **R2** — PWA (manifest + SW). 1 дн.
3. **V3** — PocketBase на VPS: initData-валидация (MAX + TG) + `/score`. 1–2 дн.
4. **V1** — реферальный deep link + бонус. 1 дн.
5. **Фаза 0** — сабмит TG Mini App Store + карточка MAX (контент-набор). 1 дн.

Параллельно: создать TG-бота (grammY, MIT) + MAX-бота — каркас для V7
(startapp, реф-база, push).

Итого за неделю: игра измерима, устанавливаема, имеет доверенный топ, реферал
и бота с push-возможностью — база для soft launch и VK-расширения.
